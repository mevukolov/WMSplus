# Iframe прогресса ОПП для WEEEK

Страница: `opp_shift_iframe.html`

Она ничего не пишет в базу и не трогает Telegram-уведомления. Только читает готовый кэш из `opp_reports_cache`:

- основной отчет: `opp_telegram_shift`
- fallback основного отчета: `opp_dashboard_shift`
- отставание: `opp_telegram_rolling30`
- fallback отставания: `opp_dashboard_rolling30`

## URL для вставки

После публикации сайта вставь в WEEEK iframe/встраиваемый блок такой URL:

```text
https://ТВОЙ-ДОМЕН/opp_shift_iframe.html?wh_id=50144199&refresh=60
```

## Параметры

- `wh_id=50144199` - склад/СЦ.
- `refresh=60` - автообновление раз в 60 секунд. Минимум 30 секунд.
- `date=2026-07-31` - опционально, показать конкретную смену.
- `shift_id=shift:2026-07-31` - опционально, показать конкретную смену по id.
- `scope=opp_telegram_shift` - опционально, основной cache_scope.
- `lag_scope=opp_telegram_rolling30` - опционально, cache_scope для отставания.

## Что показывает

- Смену и актуальность кэша.
- Сотрудников по смене.
- Проценты: `Разобрано ШК`, `Сумма`, `Дорогостой`.
- Количество выгрузок, которые требуют внимания.
- Карточки по выгрузкам со статусом, процентами и исполнителями.
- Компактный блок отставания.

## Важно

Если страница пишет, что нет `shift_dynamics`, значит в Supabase еще не обновился кэш `opp_telegram_shift` или он пришел без блока смен.
