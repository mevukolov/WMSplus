# Установка print-bridge на Windows 10 ПК с USB-принтером

Разовая настройка на том компьютере, к которому физически подключён
термопринтер (TSC DA220) по USB.

## 1. Подключить принтер и узнать его имя в Windows

1. Подключите принтер по USB, включите его.
2. Windows либо сама поставит драйвер, либо предложит скачать. Если нет —
   поставьте официальный драйвер TSC с их сайта (найдите модель DA220).
3. Откройте **Панель управления → Устройства и принтеры** (или
   **Параметры → Bluetooth и устройства → Принтеры и сканеры**).
4. Найдите принтер в списке и **скопируйте его имя ровно как написано**
   (например `TSC DA220`) — оно понадобится в шаге 4. Регистр и пробелы
   должны совпадать точно.

Драйвер печати сам ничего не портит: скрипт `send-raw.ps1` посылает байты
напрямую через спулер Windows в обход обработки драйвером, так что не
важно, какой именно драйвер стоит.

## 2. Поставить Node.js

1. Скачайте LTS-версию с [nodejs.org](https://nodejs.org) (Windows
   Installer, .msi).
2. Запустите установщик, везде оставляйте настройки по умолчанию (galочка
   "Add to PATH" уже включена).
3. Проверьте: откройте **PowerShell** и выполните `node --version` —
   должна вывестись версия, а не ошибка.

## 3. Скопировать папку `print-bridge` на этот ПК

Перенесите папку `print-bridge` целиком (флешкой, облаком — как удобно),
**кроме** папки `node_modules` внутри неё (её пересоздаст `npm install`).
Файл `.env` переносить тоже не нужно — заведёте новый на месте (шаг 4).

Положите папку куда-нибудь постоянное, например `C:\wmsplus\print-bridge`
(путь не менять потом — он зашит в `start.bat` относительно, но лучше не
переносить папку после настройки Task Scheduler).

## 4. Настроить зависимости и `.env`

1. Откройте PowerShell, перейдите в папку:
   ```
   cd C:\wmsplus\print-bridge
   ```
2. Поставьте зависимости:
   ```
   npm install
   ```
3. Скопируйте `.env.example` в `.env` и откройте `.env` в блокноте.
4. Заполните:
   - `SUPABASE_URL` — уже прописан в примере, не трогайте.
   - `SUPABASE_SERVICE_KEY` — возьмите в Supabase Dashboard → Project
     Settings → API → **service_role** key (это секрет уровня сервера,
     не тот anon-ключ, что в браузерном коде). Никому не пересылайте и
     не коммитьте — файл `.env` уже в `.gitignore`.
   - `PRINTER_NAME` — имя принтера из шага 1, ровно как в Windows.

## 5. Проверить вручную перед автозапуском

Из той же PowerShell:
```
npm start
```
В консоли должно появиться:
```
[print-bridge] starting, printer target: TSC DA220
[print-bridge] realtime subscription status: SUBSCRIBED
```
Оставьте это окно открытым и поставьте в очередь любое реальное задание
на печать (например через кнопку печати в существующем флоу) — стикер
должен напечататься. Проверьте кириллицу, позиционирование текста.

Если печать не идёт — в консоли появится текст ошибки от `send-raw.ps1`
(например `OpenPrinter failed (Win32 error ...)`, что почти всегда значит
`PRINTER_NAME` не совпадает с именем в Windows дословно).

Когда убедились, что печатает — закройте окно (Ctrl+C) и переходите к
автозапуску.

## 6. Автозапуск через Планировщик заданий (Task Scheduler)

1. Откройте **Планировщик заданий** (Task Scheduler) через поиск в Пуск.
2. **Создать задачу...** (не "простую задачу" — нужны доп. настройки).
3. Вкладка **Общие**:
   - Имя: `WMS+ print-bridge`.
   - **Выполнять вне зависимости от регистрации пользователя** — если
     хотите, чтобы работало и без входа в систему (спросит пароль
     учётки). Проще оставить "Выполнять только при входе пользователя в
     систему", если ПК всегда под одной учёткой и не перезагружается без
     присмотра.
4. Вкладка **Триггеры → Создать**: **При запуске компьютера** (или **При
   входе в систему**, если выбрали такой вариант выше).
5. Вкладка **Действия → Создать**:
   - Действие: **Запуск программы**.
   - Программа/сценарий: `C:\wmsplus\print-bridge\start.bat`
   - Рабочая папка (необязательно, `start.bat` сам переходит в свою
     папку через `%~dp0`).
6. Вкладка **Условия**: снимите галочку **Запускать только при питании от
   сети** (это не ноутбук, но на всякий случай).
7. Вкладка **Параметры**:
   - Поставьте галочку **Перезапускать при сбое каждые: 1 минута**,
     **Число попыток перезапуска: 999** — так процесс сам поднимется,
     если упадёт (сеть моргнула, принтер на секунду отвалился и т.п.).
8. Сохранить, при запросе пароля — ввести пароль учётки Windows (нужен
   для варианта "вне зависимости от регистрации").

Проверьте: перезагрузите ПК и через минуту откройте
`C:\wmsplus\print-bridge\print-bridge.log` — там должны быть свежие
строки `[print-bridge] starting...` и `SUBSCRIBED`.

## Если что-то пошло не так

- `print-bridge.log` — первое место для проверки, туда пишется всё то
  же, что раньше видели в консоли.
- Ошибка `OpenPrinter failed` — почти всегда неверный `PRINTER_NAME`.
  Сверьте точное написание в Устройствах и принтерах.
- Задания зависают в статусе `queued` и не появляются в логе вообще —
  процесс не запущен или не может достучаться до Supabase (проверьте
  интернет на этом ПК и `SUPABASE_SERVICE_KEY` в `.env`).
